# Netmojo Systems

Agent-forward software development. Move fast, and make things.

## Current Projects

- [omdrop-plugin](https://github.com/netmojo-systems/omdrop-plugin): send and receive files with nearby Apple devices over AirDrop, on Apple Silicon Macs running [Omarchy Linux](https://omarchy.org/).
- [omdrop-awdl](https://github.com/netmojo-systems/omdrop-awdl): AWDL (the AirDrop link layer) driver support for the Broadcom BCM4387, as `brcmfmac` patches and a DKMS package.
- [pearpass-app-desktop](https://github.com/netmojo-systems/pearpass-app-desktop): our fork of the PearPass desktop password manager. I haven't started work on this yet, but it is a viable alternative to 1Password on Omarchy. It needs integration with TouchID on Macs, and I plan to update Omdrop to use it for Apple Airdrop keys, for Contacts Only mode.
