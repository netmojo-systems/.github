# Netmojo Systems

Agent-forward software development. Move fast, and make things.

## Current Projects

- [omdrop-plugin](https://github.com/netmojo-systems/omdrop-plugin): send and receive files with nearby Apple devices over AirDrop, on Apple Silicon Macs running [Omarchy Linux](https://omarchy.org/).
- [flea-omdrop](https://github.com/netmojo-systems/flea-omdrop): send selected files from the [Flea file manager](https://github.com/thisisgm/flea) to nearby Apple devices through Omdrop. Install from Git or use the [prebuilt Arch package](https://github.com/netmojo-systems/flea-omdrop/releases/latest).
- [omdrop-awdl](https://github.com/netmojo-systems/omdrop-awdl): AWDL (the AirDrop link layer) driver support for the Broadcom BCM4387, as `brcmfmac` patches and a DKMS package.
- [omp-buzz](https://github.com/netmojo-systems/omp-buzz): A plugin for the [omp](https://omp.sh/) agentic IDE that allows agents to connect to Block's [Buzz](https://buzz.xyz/) human/agent chat app. Users can run their own Buzz server locally. Agents and humans alike get a Slack-like workspace chat app, with topic channels, reply threads, direct messages, etc., to communicate over shared project work. Buzz has mobile and desktop apps, and is based on the amazing NOSTR protocol for decentralized communication.
